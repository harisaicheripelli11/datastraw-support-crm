# SupportCRM — Datastraw AI + Tech Intern Assessment

A responsive customer support ticketing CRM built with FastAPI, SQLite, HTML, CSS, and Vanilla JavaScript.

## Live Demo

**Live Application:**  
https://datastraw-support-crm-production-8af6.up.railway.app

**GitHub Repository:**  
https://github.com/harisaicheripelli11/datastraw-support-crm

## Features

- Create customer support tickets
- Automatic ticket IDs such as TKT-001
- Automatic ticket timestamps
- Search by ticket ID, customer name, email, subject, and description
- Filter by Open, In Progress, and Closed
- Ticket detail view
- Update ticket status
- Add internal notes
- Priority indicator
- Dashboard ticket statistics
- Responsive desktop/tablet/mobile UI
- REST API with FastAPI
- SQLite database
